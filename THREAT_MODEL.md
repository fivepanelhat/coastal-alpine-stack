# Coastal Alpine Tech - Threat Model & Defense Matrix

This matrix outlines the targeted threat vectors across the stack, the corresponding defensive mechanisms implemented, and their blast radius isolation boundaries.

| Layer / Threat Vector | Core Security Risk | Implemented Defensive Mechanism | Targeted Repository / Location | Blast Radius Isolation |
| :--- | :--- | :--- | :--- | :--- |
| **Physical / Hardware** | Node theft, SD card extraction, malicious code injection via physical access. | Secure Boot (Locked EEPROM) & TPM 2.0 Remote Attestation (PCR 0-7 validation). | `Sovereign-Edge-Firmware` <br> `Coastal-Alpine-Core` | Absolute. Stolen nodes cannot spoof identity without the physical silicon; modified filesystems refuse to boot. |
| **Operating System** | Filesystem corruption during site power cuts; runtime host takeover. | Immutable Root Filesystem (`overlayfs` + RAM-backed `tmpfs` buffers for Hailo-10H NPU caches). | Pi 5 Host Configuration | System-wide. Filesystem degradation is mathematically impossible; OS resets to pristine baseline on reboot. |
| **Network Transit** | Packet sniffing on local site Wi-Fi; credential harvesting; man-in-the-middle attacks. | Mutual TLS (mTLS) on Port 8883 + Asymmetric ES256 Local JWTs passed as MQTT passwords. | `Weaver` <br> `Sovereign-Edge-Firmware` | Traffic-wide. In-flight data is fully encrypted; broker drops connections instantly if client certificates fail to validate. |
| **Network Architecture** | Lateral network movement from a cracked web gateway to a sensor array. | Micro-Segmentation via `nftables` host firewall + strict topic-level Mosquitto ACLs. | `Weaver` / Pi 5 Kernel | Segmented. Compromising a web portal gives zero network line-of-sight to internal edge vision or database nodes. |
| **Application / API** | Brute force API hammering; rogue or out-of-bounds actuator triggers. | Command Rate-Limiting + Behavioral Analytics Engine (chronological and velocity boundary checking). | `AquaGuard-Portal` <br> `Coastal-Alpine-Core` | Process-wide. Toxic or anomalous actuation payloads (e.g., flooding a crop at 2 AM) are blocked at the parsing boundary. |
| **AI / Inference** | Adversarial prompt injection; model manipulation; data input poisoning. | Input Guard Check (Firmware state hash matching) + Prompt Sanitization Matrix inside CI pipeline. | `Sting-Operation-AI` <br> `Coastal-Alpine-Core` | Model-wide. Malicious strings or unauthorized firmware payloads are quarantined before processing by the Hailo NPU. |
| **Data / Storage** | NVMe drive harvesting; extraction of local telemetry caches and historical yield data. | Transparent 256-bit AES Encryption-at-Rest via SQLCipher integration using high-entropy local keys. | `SoilGuard-Portal` <br> `Coastal-Alpine-Core` | Data-wide. Raw database files extracted from physical storage are unreadable chunks of noise without the local environment keys. |
| **Supply Chain** | Accidental commit of API keys; rogue upstream library injections. | Local Git `detect-secrets` scanning + Private GitHub Packages automated dual-registry pipeline. | `Coastal-Alpine-Core` <br> All repositories | Repo-wide. Credentials can't escape to the open web; dependencies are checked daily via CodeQL and blocked if malicious. |
| **Observability / Audit** | Blind spots during offline outages; regulatory non-compliance under the NZ Privacy Act. | Local Prometheus/Grafana Scrapers + Sequentially Chained Sustainability & Compliance Audit Log Engine. | `Weaver` <br> `Coastal-Alpine-Core` | Auditable. Tamper-proof log chains guarantee chronological accountability for every system actuation while tracking carbon metrics. |
